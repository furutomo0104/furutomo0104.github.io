# 筋記録 プライバシーポリシー

制定日：2026年10月15日

古田朋也（以下「運営者」）は、iPhone アプリ「筋記録」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

## 1. トレーニング記録について

本アプリに入力したトレーニング記録（種目、重量、回数、メモなど）は、お使いの端末内にのみ保存されます。運営者のサーバーに送信されることはなく、運営者がこれらの記録を閲覧・収集することはありません。

## 2. 広告について

本アプリの無料版では、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。AdMob は、広告の配信・効果測定・不正防止のために、端末の情報（端末の種類、OS のバージョン、IP アドレスなど）や広告の表示・タップの状況を収集する場合があります。

本アプリは、他社のアプリや Web サイトをまたいだ利用者の追跡（トラッキング）の許可を求めておらず、トラッキングは行いません。

Google による情報の取り扱いについては、以下をご確認ください。

- [Google プライバシーポリシー](https://policies.google.com/privacy)
- [Google のサービスを使用するサイトやアプリから収集した情報の Google による使用](https://policies.google.com/technologies/partner-sites)

## 3. 有料プラン（PRO）の購入について

有料プランの決済は Apple の App Store を通じて行われます。運営者がクレジットカードなどの決済情報を取得することはありません。

購入状態の管理のために RevenueCat, Inc. のサービスを利用しており、匿名のユーザー ID と購入履歴が同社に送信されます。詳しくは [RevenueCat のプライバシーポリシー](https://www.revenuecat.com/privacy) をご確認ください。

## 4. 第三者への提供

運営者は、上記のサービスを除き、利用者の情報を第三者に提供することはありません。

## 5. データの削除

本アプリを端末から削除すると、端末内に保存されたトレーニング記録も削除されます。

## 6. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。
